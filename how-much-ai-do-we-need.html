How much AI do we need?

My thoughts and learnings from using open weight models and local AI.

By Joy Heron

This site is also available as a slideshow.

Timeline of my AI usage

  • Summer 2025: consistent $200-300 token spend per month
  • Autumn 2025: Switch to GPT models with subscription
  • Spring 2026: OpenAI increases pricing and I reach my token limits daily 👀

Different model sizes

  • Small: deepseek-v4.1-flash, glm-53-flash, qwen3.6-a3b-27b, Haiku (Anthropic), Luna (OpenAI)
  • Medium: glm-5.3, Sonnet (Anthropic), Sol (OpenAI)
  • Large: kimi-k3.1-pro, Opus (Anthropic), Fable (Anthropic), Astra (OpenAI)

Learning: If you always break down the work into chunks which are small enough for a human to review, medium sized models are good enough.

Learning: Inference is expensive

I'd gotten used to paying <$100 a month with subscriptions, but using GLM 5.2 as a drop in replacement cost 200-300$

Learning: Focusing on token expenditure kills my productivity

After spending "so much" for one month, I tried to reduce costs by reaching for cheaper models and keeping myself more in the loop -- negating a lot of the benefits of agentic software engineering.

Learning: Using a model which is too small is a waste of time/money

If a smaller model isn't able to execute a task well, you end up redoing loads of work and having to give fine granular instructions. Or just redoing it all with a larger model.

For what tasks CAN we use smaller models?

  • Please write a unit test for method XYZ
  • Please write a guided tour of the changes in this commit
  • Please read this transcript of our audio and extract an ADR with the topics that we discussed
  • Add a column to the table to show WXY
  • Rule of Thumb: If it touches 1-2 files + tests, a smaller model might do a good (enough) job

When you have access to different models and use them for different tasks, you do develop a bit of "muscle memory" for which model might be good for different tasks.

In the future we will likely be able to combine the new decision models to choose the proper model for executing a task and dynamically choosing an appropriate model. 😍

Learning: Don't use Agents for tasks which are highly deterministic

copy/paste with Agents is expensive. With a script it's free.
